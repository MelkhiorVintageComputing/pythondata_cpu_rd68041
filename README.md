# pythondata-cpu-rd68041

The SystemVerilog of [RD68041](https://github.com/MelkhiorVintageComputing/RD68041),
an MC68040 (`FPU = 1`) or MC68LC040 (`FPU = 0`), packaged for LiteX
(`get_data_mod("cpu", "rd68041")`).

Generated by `litex-68k/scripts/sync_pythondata_rd68041.sh` from RD68041 commit
`c5ba651cab654a0c6f410bfa071283938a6cfabf` (`c5ba651`). Do not edit; regenerate.

- `pythondata_cpu_rd68041/verilog/rtl/`: the RTL, as in RD68041's `rtl/`.
- `pythondata_cpu_rd68041/verilog/rd68041.f` and `pythondata_cpu_rd68041.sources`: the files in compile order.
- `pythondata_cpu_rd68041/verilog/rtl/rd68041.vlt`: RD68041's Verilator waivers.

Reciprocal (`LICENSE`).
